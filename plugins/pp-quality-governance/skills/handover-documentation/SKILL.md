# Handover pack

- Architecture summary and solution inventory (solutions, versions, owners)
- Environment list, URLs, service accounts and who rotates secrets
- Admin guide: security roles, user onboarding, how to deploy a release
- Support runbook: common errors, flow failure triage, where logs are
- Known issues, backlog and recommendations
- Training material pointers and sign-off
